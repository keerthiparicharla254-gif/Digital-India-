DIGITAL INDIA WEB APPLICATION PROTOTYPE

Included:
1. index.html       - Home/Dashboard
2. services.html    - Government Services
3. request.html     - Service Request Form
4. about.html       - About + B.Tech CSE connection
5. contact.html     - Contact page
6. style.css        - Complete responsive design
7. script.js        - Navigation, search and form demo functionality

HOW TO USE:
Extract the ZIP folder.
Keep all files in the same folder.
Open index.html in Chrome, Edge or another browser.

NOTE:
This is a frontend prototype for a college/business project. The forms currently show demo success messages and do not store data in a real database.
